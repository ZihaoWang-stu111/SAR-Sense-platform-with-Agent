— Chapter 01

从粗粒像素到
毫秒级判定

SAR 图像里的船舶，往往只是几个像素的回波。我们用 YOLO v8 驱动的视觉引擎，将每一帧拆解、定位、再重组成一份可视化的检测报告 —— 过程从上传到出图，平均 87 毫秒。

重要的不是更高的数字，而是 判读的可重复性。每一次推理都被序列化， 每一个边界框都可以被审计、被回放、被解释。

  • YOLO v8 视觉引擎 · 实时推理 < 100 ms
  • 多尺度目标检测 · 适应粗粒和细粒像素
  • 边界框 + 置信度 + 元数据，三件套可审计
— Chapter 02

当智能体替你
追问下一步

一份检测结果是终点，还是起点？我们更愿意它是后者。 SAR-Sense 内置 ReAct 架构的 LangChain 智能体，会把"识别到的船舶" 自动延展为"它是谁、从哪里来、风浪是否合宜"等下一步分析。

13+ 专业工具被精心策划，每一次调用都被中间件全程监控、分级记录。 思维链可视化让你看见模型的每一次试探。

  • ReAct 推理架构 · 流式输出
  • 13+ 工具策划集（天气 / 海况 / RAG / Web / 报告生成）
  • 思维链可视化 · 每一步可追溯

— Chapter 03

把领域知识
留在你的舱内

最锋利的 AI 仍要被领域知识喂养。我们把 RAG 设计成可被你拥有的形态： ChromaDB 作为底座，混合检索（向量 + BM25）作为入口， 父子块结构化分块让每一次召回都不丢失原文上下文。

BGE Reranker 在子块层精修排序，再回表聚合成父块 —— 兼顾准确性与可读性，回答里的每一句话都能定位到 PDF 的哪一段。

  • ChromaDB 向量库 · 本地化部署
  • 混合检索 · 向量 ⊕ BM25 双通道
  • 父子块结构 · 子块召回，父块呈现
  • BGE 重排 · 子块层精修，父块继承秩序
Our Tenets

克制即奢华
精确即信任

六条我们坚持的原则 —— 它们决定了 SAR-Sense 不是另一个普通的 AI 工具。

i.

Engineered
for the eye

每一处玻璃、每一条阴影、每一段斜体编号，都用 Apple Liquid Glass 与 Hermès editorial 的标准对齐。

ii.

Local
by default

ChromaDB 与 YOLO 权重均本地化部署，数据不出内网。私密性与合规性是默认选项，而非升级套餐。

iii.

Auditable
at every step

从工具调用到 LLM 推理，每一帧都被 LangChain 中间件结构化记录。可观测性是工程伦理的一部分。

iv.

Concurrent
by design

RAG 流水线为并发查询设计：reranker 不修改入参，BM25 共享对象通过 copy-on-write 隔离。

v.

Tested
not assumed

50 题手工策划评测集，5×3 消融实验。Recall@5 / MRR 都有数字而非感觉，迭代有方向不靠猜。

vi.

Premium
by restraint

没有花哨的 emoji，没有过载的霓虹。我们相信少即是多 —— editorial 排版与香槟金的克制点缀。
